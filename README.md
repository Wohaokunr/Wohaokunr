## About

I'm a developer interested in **AI agents, automation, bot infrastructure, and interactive software**.

目前主要在做能够真正长期运行的 Agent / Bot 项目：不仅关注模型效果，也关注记忆、上下文、交互设计、可观测性、部署与维护。

I prefer turning experiments into software that can actually be deployed, operated, and iterated on.

## Selected work

### [YawnBot](https://github.com/Wohaokunr/yawn_bot)

A modular QQ bot built on **NoneBot2 + OneBot V11**, with a focus on group-chat agents and long-running interactive experiences.

- Group agents with memory, profiles, relationships, proactive messaging, and media capabilities
- RPG and Werewolf game systems with persistent state and AI participants
- FastAPI-based management WebUI with scoped guest access
- Docker deployment, database migrations, CI/CD, and production-oriented tooling

### [YawnNoir](https://github.com/Wohaokunr/YawnNoir)

An experimental **Unity visual-novel system** for building branching stories with editor-driven narrative graphs.

- Dialogue, choices, conditions, effects, jumps, and reusable story structures
- ScriptableObject-based content workflow
- AI NPC conversations embedded into authored narrative flows
