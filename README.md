## 代表项目

### [YawnBot](https://github.com/Wohaokunr/yawn_bot)

一个基于 **NoneBot2 + OneBot V11** 的模块化 QQ 机器人项目，主要探索群聊 Agent 与长期运行的交互式体验。

- 群聊 Agent：记忆、用户画像、关系网络、主动发言与多媒体能力
- RPG 跑团与狼人杀系统：持久化状态、完整流程与 AI 玩家
- 基于 FastAPI 的管理 WebUI，并提供受限的访客只读访问
- Docker 部署、数据库迁移、CI/CD 与面向生产环境的运维工具

### [YawnNoir](https://github.com/Wohaokunr/YawnNoir)

一个实验性的 **Unity 视觉小说系统**，用于通过编辑器驱动的剧情图构建分支叙事。

- 对话、选项、条件、效果、跳转与可复用剧情结构
- 基于 ScriptableObject 的内容工作流
- 将 AI NPC 对话嵌入预先编排的剧情流程
